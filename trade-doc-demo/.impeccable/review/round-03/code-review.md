### [MEDIUM · Resolved] 链接默认导航绕过未提交输入确认

位置：`js/views-docs.js:124`、`:166` 的 `doc-leave` 链接和 `:152` 的动作。调用链为 `app.js:319` 的 `fn(el, e)`。

原失败：有未提交包装或审核意见时点“全部单证台账”或“关联订单”，动作虽打开离开确认，却没有阻止 `<a href>` 默认 hash 导航；浏览器仍可重建页面，取消确认不能保留原输入。目录 `doc-goto` 使用 button，不受该默认行为影响。

修正：`doc-leave(el, event)` 调用 `event.preventDefault()` 再进入共用离开检测。审查独立动作事件夹具已验证：有审核意见时确认打开、`defaultPrevented=true`、确认前 hash 和意见不变。第二轮独立运行 `verify-document-workspace.cjs`，进一步用真实 `app.js` 委托、`U.confirm/openModal` 和最小 DOM 验证链接默认行为被阻止，取消离开保留意见/包装节点与输入，确认后才跳转；仍不把 Node DOM 夹具当浏览器证明。
