## 结构和状态

地图插在四指标之后、原 `.dash-grid` 之前，以一个全宽白面板承载“标题/样例范围/重播 → 点阵地形与国家节点 + 右侧分币种金额和订单 → 国家文字按钮/边界说明”。原待办、近期四笔订单、三类进度和侧栏顺序保留；国家选择仅影响地图右栏。地图使原内容向下延续，旧规范关于此前首屏位置的测量不能直接用于本次扩展后的工作台。

桌面默认使用弹性地图与 300px 右栏，gap 24px；1360px 以下右栏为 270px、gap/右栏内边距 18px。左右最小宽为 0，明细保留滚动条位置；204px 高列表容纳三条至少 68px 记录，超过三笔显示向下滚动提示。沿用项目 1280px+ 桌面范围，本报告不追加移动端承诺。

| 状态 | 源码确认的表达 |
|---|---|
| 默认全部 | “全球订单”、订单数/已定位国家数；“演示全量样例 · 含所有订单状态”；全部国家右栏 |
| 国家选中 | 地图和底部同名按钮同步 `aria-pressed=true` 与紫色选择面；右栏标题、笔数、分币种金额和订单随选项更新 |

以上异常分支已核源码；独立 finish review 也明确这些状态没有本轮逐一截图，不能称全部异常态已目视。

## 键盘、动效和数据边界

地图国家节点、下方等价国家按钮及重播均为原生 `button type=button`，订单为真实 hash 链接。国家按钮具名且有笔数，以 `aria-controls` 关联右栏；装饰地形图片和 SVG 隐于无障碍树，SVG 不取得键盘焦点。筛选动作不重建画布和按钮，仅更新 pressed、右栏内容及独立 `role=status` 短播报，不自动移动焦点。现有成功身份切换清理除导航展开外的 AppUI 临时状态，因此地图国家选择也被清理；不会写 localStorage 业务持久数据。

静态点、晕圈和虚线保持可见；光迹默认各执行一次 2800ms、每条错开 120ms，沿用现行 `cubic-bezier(.16,1,.3,1)`，最终透明。重播仅重启这一次视觉过程；`prefers-reduced-motion:reduce` 同时受全局和地图 CSS 停用，重播动作在当前设置下短播报保留静态分布。此 2800ms 为本地图一次性表达，不替代全局 140–280ms 操作反馈节奏，也不表示业务成功。

地图读取当前内存全量订单，按唯一关联客户的国家分组，保留所有订单状态；不是生产“业务员仅本人负责业务”的实现。配置的六国中只有有订单的国家绘点。汇总复用 `U.transactionAmounts` 的逐行到分结果，按币种累加安全整数分并核无损显示；不同币种分行，不折算、不合并成总额。当前 7 笔/5 国、USD 122,200.00 与 EUR 70,000.00 是主代理运行记录和独立终评记录的样例基线，本角色未独立重算。

国家锚点为人工近似中心，标签通过引导线错开；流动线没有实际出货起点。页面明确“国家锚点为示意位置；连线为视觉效果，不表示物流路线”。本地 Natural Earth 110m land SVG 是无政治边界的地理示意，来源/许可与输入输出哈希由 `assets/maps/README.md` 记录，本角色未访问远端复验原始下载真实性或地理精度。页面无新增运行时网络请求、外部库/字体、构建工具或运行脚本。本轮无 shipping raster；JPEG 终图仅为 QA 证据。
