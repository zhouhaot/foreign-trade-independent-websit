- 登录、快捷切换、部门、工作区、管理员列表及财务计数采用岗位／本地会话等中性表述；未接认证、不校验密码、勿填真实凭据及刷新还原仍明确保留。
- 起运地和合成询盘改为“合成数据”，保留逐单来源、非真实需求和样例加入日期；仅精确适配已知 INQ6 文本，任意业务原文保留。
- 原来只写历史的文件操作改为“登记导出记录”，按钮、资格、审核提示、结果和新历史一致说明不生成文件。旧精确动作仅适配显示，原历史不改。
- 原“重置密码”假成功改为“密码服务说明”，明确不修改密码、不发通知；确认仍保原身份与对象重查。
- 现有金额规则、三进度、受控修订、岗位资格、刷新行为及 A 紫色不变。原 Mock 与三份 CSS 字节未改，内部 ID／会话键／数据标记不重命名。入口 JS 缓存版本统一为 `20261019-copy`。

本轮采用 impeccable 的清晰文案及能力真值原则：删除冗余标签，同时收回两处未实现能力的成功承诺。没有因去词更换布局、调色或开展未授权生产工程。
