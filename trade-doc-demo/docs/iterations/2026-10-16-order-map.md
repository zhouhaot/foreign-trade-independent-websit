# 工作台全球订单可视化

## 范围与前后行为

需求方确认将参考页全球交易点阵/光点/流动线加入工作台，沿用A紫色，保留原订单区。之前工作台只有角色指标、待办、近期订单与侧栏；现在指标下有全球订单地图，地图标签或下方同名文字按钮可选择国家，右侧显示对应订单和分币种合计。链接仍走原权限路由；国家筛选不改变近期订单、订单列表筛选或业务数据。

## 实现和假设

- `js/views-core.js`：私有地图视图/金额聚合，`U.orderMapData`、两个委托动作；无额外全局、事件监听或运行脚本。`css/pages.css`追加地图局部样式。入口仍3CSS/9JS。
- 复用现有订单详情模块资格；管理员和禁用该模块的角色不展示，操作重查。当前Demo全量样例不等于正式本人数据隔离；没有改生产方案或旧角色规则。
- 订单按当前客户唯一记录的国家分组，含所有订单状态。近似国家锚点不代表客户地址；客户缺失、重复或未知国家统一地点待补，不默认到中国或推断城市。6个已配置国家中英国无订单，不画虚假光点。
- 总额复用逐行精确到分的`U.transactionAmounts`，按币种累加安全整数分，并检查可无损显示；异常币种/明细/溢出明确待核对，不默认为0或跨币种折算。基线7笔/5国：USD122,200.00、EUR70,000.00。
- 流动线无实际出货起点，只作视觉引导；默认一次2800ms，每条错开120ms，可重播；减少动效完全停用动画但保留静态点和筛选。没有常驻后台动画或动画完成即业务成功。
- 原待办、近期订单四笔及三类状态、单证/财务写流程未改。选择只更新右侧与pressed/live短提示，不重建画布、按钮或工作台其他节点。
- 地形是Natural Earth公共领域数据离线生成的本地SVG，来源、输入/输出哈希及投影边界见`assets/maps/README.md`；不调用外部地图、不复制参考站代码或图片。
