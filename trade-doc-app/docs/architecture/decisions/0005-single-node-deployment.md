# ADR-0005：单机部署

- 状态：Accepted
- 日期：2026-10-29

## 背景

目标为约 15 名内部员工的首版系统，已选择服务器部署。当前没有证据支持微服务、多节点或无服务器平台的额外复杂度，服务器具体规格仍未核实。

## 决策

首版采用单台服务器上的一个 Next.js 生产应用实例和一个 PostgreSQL 主库，同源反向代理终止 HTTPS 并仅暴露必要入口。数据库不公开到业务网络之外，应用数据库账户只拥有所需权限，连接数设置有界。业务 API 保持 `/api/v1`，Demo 不参与部署或数据初始化。

不采用多应用副本、读写分离、消息队列、Kubernetes 或独立工作流平台。会话、幂等和审计全部持久化到 PostgreSQL，不依赖进程内状态；但单库和单应用实例仍是可用性单点，不宣称高可用或零停机。

部署、迁移和回滚采用受控维护窗口。秘密仅由服务端环境/秘密管理提供，不进入 Git、客户端包或日志。服务器规格、TLS 证书、备份保留、恢复时间/数据损失目标和监控告警在试运行前确定；数据库与后续附件需一致备份，并在隔离环境实际恢复演练。

## 后果

架构和运维保持简单，适合当前小规模内部使用。容量、连接限制和备份窗口需按真实硬件测量。未来扩容必须重新评估会话、连接池、迁移和备份策略，并通过新 ADR；不能简单增加副本后假定并发正确。

## 历史候选

旧 NAS、Spring Boot 部署和 MySQL 运维示例仅为历史候选，不证明当前服务器、容器或数据库条件已经具备。
